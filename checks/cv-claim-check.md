# CV Claim Check

Use this before you accept a rewritten summary, experience section or application answer.

## Check Every Claim

For each statement, ask:

1. Where is the evidence for it in the source CV or confirmed notes?
2. Does the wording make the responsibility sound bigger?
3. Has a shared contribution become sole ownership?
4. Has a task become an achievement with no result?
5. Has a related skill become direct experience?
6. Has an estimate become an exact number?
7. Has industry jargon changed what it means?

## Labels

| Label | Meaning |
| --- | --- |
| Supported | Directly evidenced and fairly described |
| Needs confirmation | Plausible, but the source is incomplete |
| Overstated | Based on real experience, but stronger than the evidence |
| Invented | Not supported by the information given |

Only supported claims go in a finished CV. Check uncertain facts with the person rather than guessing.

## Final Questions

- Could the person explain this statement clearly in an interview?
- Is the achievement still true without the impressive adjectives?
- Are dates, figures and responsibilities the same everywhere they appear?
- Does anything give away confidential customer or employer information?
